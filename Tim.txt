Teknologi yang Digunakan:
- Runtime       : Node.js v18+
- Framework     : Express.js v4
- ORM           : Sequelize v6
- Database      : SQLite (Development) / PostgreSQL via Neon (Production)
- Frontend      : React 18 + React Router v6
- Build Tool    : Vite 5
- Styling       : Tailwind CSS v3
- Autentikasi   : Passport.js (Local + JWT + Google + GitHub) + bcryptjs
- RTC           : WebRTC (RTCPeerConnection + RTCDataChannel) + STUN
- Deployment    : Vercel (Frontend static + Backend serverless)

Link Template:
- Tampilan dibangun dan dirancang secara mandiri dari awal (from scratch) menggunakan Tailwind CSS.
- Tidak menggunakan template pihak ketiga.

Inovasi & Kreativitas pada Tampilan dan Fungsionalitas Web:

1. Arsitektur OOP dengan Inheritance:
   Menggunakan pola BaseModel (class inheritance) untuk seluruh 7 model database,
   sehingga operasi CRUD terstandarisasi dan reusable di semua resource.

2. Full-Stack POS (Point-of-Sale) System:
   Bukan hanya CRUD sederhana, tetapi sistem kasir lengkap dengan fitur:
   - Keranjang belanja real-time
   - Checkout dengan pilihan Pickup/Delivery
   - Integrasi kode promo (percent & fixed discount)
   - Kalkulasi otomatis subtotal, diskon, dan ongkir

3. Role-Based Authentication & Authorization:
   JWT Authentication dengan middleware terpisah untuk auth & admin.
   Admin mendapat akses penuh ke dashboard + CRUD semua resource.
   Customer hanya bisa browse menu, order, dan validasi promo.

4. Admin Dashboard dengan Statistik Real-Time:
   Panel admin lengkap dengan statistik ringkasan (total order, revenue,
   produk, user, pending orders) menggunakan raw SQL query yang efisien.

5. Filter, Search & Pagination Dinamis:
   - Live search produk berdasarkan nama
   - Filter berdasarkan kategori
   - Pagination di semua resource (products, orders, users, promos)
   - Filter status order (pending/processing/completed)

6. Desain Premium & Interaktif:
   - Glassmorphism effect dengan backdrop blur
   - Micro-animasi (hover, fade-in, slide-up, scale)
   - Typography premium (Google Fonts: Inter + Playfair Display)
   - Custom scrollbar dengan gradient
   - Toast notification animasi
   - Fully responsive (desktop hingga mobile)

7. Dual Database & Cloud Deployment:
   Konfigurasi mulus antara SQLite untuk development lokal dan
   PostgreSQL (Neon) untuk production di Vercel serverless.

8. WebRTC Live Video Support (RTC):
   - Video call real-time P2P antara customer dan admin via WebRTC
   - Live chat menggunakan RTCDataChannel (peer-to-peer)
   - Signaling via REST + DB polling (karena Vercel serverless)
   - STUN server untuk NAT traversal cross-network
   - Customer: tombol "Live Support" → video call ke admin
   - Admin: notifikasi otomatis panggilan masuk → Accept/Decline
   - Fitur: mute mic, toggle camera, live chat, hangup
   - Auto-timeout jika admin tidak menjawab dalam 45 detik
